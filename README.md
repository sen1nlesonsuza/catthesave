# 🐱 Cat The Save — Ultra

2D, touch-first, high-quality arcade brick-breaker/cat rescue game.

## Özellikler
- 60 FPS requestAnimationFrame oyun döngüsü
- Mobil ve masaüstü pointer kontrolleri
- Bölümler, boss savaşları, combo ve can sistemi
- Power-up'lar ve yedek toplar
- Kostüm/mağaza sistemi
- LocalStorage ilerleme kaydı
- Ses ve isteğe bağlı titreşim
- Harici font/CDN bağımlılığı yok
- GitHub Pages için tek dosyalı web oyun yapısı

## Çalıştırma
`index.html` dosyasını doğrudan açabilir veya GitHub Pages ile yayınlayabilirsin.

## Oynanış
Kedi platformunu hareket ettir. Topu yukarı doğru sürükleyip bırak. Düşman bloklarını temizle, boss bölümlerini tamamla ve ilerle.
